# 홈 Hero + 오늘의 1면 — 2026-10-14

> [[2026-03-20-homepage-simplification]]의 연장선. Hero 중심 원칙은 유지하고, 매일 바뀌는 편집된 한 줄만 더한다.

## 배경

- 사이트 리디자인(Soft Newsprint V2) 3단계에서 V2 시안의 홈은 신문 1면 전체(머리기사 + 목록 + 오늘의 용어)였다.
- 3월 20일 결정은 "섹션 4개(뉴스·용어·제품·블로그)가 헤더 메뉴를 복제해 사용자가 길을 잃는다 → Hero만"이었고, "콘텐츠가 쌓이면 다시 추가 가능"을 남겼다.
- 선택지(Hero만 / Hero + 오늘의 1면 / 신문 1면 전체) 중 사용자가 **Hero + 오늘의 1면**을 승인했다.

## 결정

- Hero(문구·타이핑·CTA)는 그대로 두고 V2 스타일만 입힌다. 큰 제호 `0to1log.` + 모토 + 호수 줄(제N호 · 날짜 · 오늘 N건)을 더한다.
- Hero 아래에 **오늘의 1면** 하나만 둔다. 내용은 머리기사 1건(+ 같은 날 기사 한 줄)과 오늘의 용어 1개다.
- 섹션 나열이 아니라 "편집된 한 줄"이므로 메뉴 복제 문제를 다시 만들지 않는다.

## 데이터와 비용

- `lib/pageData/homeFrontPage.ts`: 뉴스 1회(limit 6, published_at desc + post_type asc), 용어 개수 1회(head), 용어 1행 1회(range).
- 홈은 CDN 캐시(`list`, s-maxage 300 + SWR 3600). 뉴스·핸드북 변경 시 `home` 태그도 무효화된다(Supabase 세션 작업).
- 홈은 모든 방문자에게 같은 화면이다. 사용자별 분기를 하지 않는다.

## 알려진 한계

- 캐시 때문에 날짜, 호수, 오늘의 용어가 KST 자정 이후 최대 약 1시간 늦게 바뀔 수 있다.
- 오늘의 용어는 발행 용어 전체를 slug 순으로 정렬해 `호수 % 개수`번째를 고른다. 용어가 추가되면 순서가 밀려 같은 날에도 바뀔 수 있다(캐시 갱신 시점).
- DB에 `is_favourite = true` 용어가 0개라서 즐겨찾기 기반 선택은 쓰지 않았다.
